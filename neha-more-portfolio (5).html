Pathwright — AI-powered learning roadmap generator

3normalized relational tables: users → roadmaps → milestones
Read case study

Problem: Someone with a target role and a rough sense of their current skills has no structured way to see what to learn next, in what order.

Approach: Built a full-stack app where a user's skills and target role are sent to an LLM, which generates a structured, milestone-based roadmap with categorized topics and resources. Outcome: A working Spring Boot REST API with proper error handling (404/502) and a responsive frontend for real-time milestone completion tracking.
